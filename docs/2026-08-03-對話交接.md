### 4. LINE 推播與雙向互動機器人（多次迭代，最終版見下）
- 最初走 GitHub Actions + LINE push API 單向推播（PR #5），後來全部升級為 Cloudflare Worker 雙向互動（PR #6），再升級為多使用者版本（PR #7，取代 PR #5/#6 的單人邏輯）
- **最終架構**：
  - `line-bot-worker/`：Cloudflare Worker，接收 LINE Webhook
    - 打股票代號（如「2330」）→ 即時查 FinMind API，回覆收盤價/漲跌/5日20日均線交叉狀態
    - 「追蹤 2454」「取消追蹤 2454」「清單」→ 操作個人追蹤清單
    - 加好友時自動註冊 + 發歡迎訊息
    - Cron Trigger（`10 6 * * 1-5`，台灣時間週一到五 14:10）：`scheduled` 函式逐一檢查每位使用者的追蹤清單，均線交叉時各自推播
  - Cloudflare KV（`WATCHLIST_KV`）：
    - key `users`：已互動過的 LINE userId 清單
    - key `watchlist:<userId>`：該使用者的追蹤清單
  - **每人追蹤清單、每人推播皆獨立**，可放心把 LINE 官方帳號分享給其他人加好友使用
- 舊的 `scripts/check_signal_and_notify.py`（GitHub Actions 內單向推播）已刪除，功能由 Worker Cron 取代
- Worker 部署網址：`https://stock-quant-line-bot.wanyu0421.workers.dev`

## 目前架構
```
FinMind（拿資料） → data/*.csv（每日 GitHub Actions 排程）
                  → data/stock_list.csv（全市場清單，一次性）
                  → scripts/backtest_ma_cross.py（策略回測）

LINE 官方帳號 ⇄ Cloudflare Worker（line-bot-worker/）
                  → 即時查詢 FinMind API
                  → Cloudflare KV（每人追蹤清單）
                  → Cron 每日推播（均線交叉，各自獨立）
```
